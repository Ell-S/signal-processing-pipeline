# Modular Time-Series & Signal Processing Pipeline

A robust, modular Python pipeline designed for processing, filtering, and extracting statistical features from high-dimensional time-series data (applicable to neural recordings, physical sensors, or quantitative data streams).

## 🚀 Key Features
- **Synthetic Data Generation:** Simulates multi-frequency signal streams combined with Gaussian noise.
- **Advanced Filtering:** Implements digital Butterworth bandpass filters via `SciPy` to isolate target frequency bands.
- **Feature Engineering:** Extracts rolling statistical metrics (mean, standard deviation, energy) using `Pandas`.
- **Automated Visualization:** Compares raw vs. processed signals and exports publication-ready figures.

## 🛠️ Tech Stack
- **Python** (Core logic)
- **NumPy & SciPy** (Signal processing & matrix math)
- **Pandas** (Feature engineering)
- **Matplotlib** (Data visualization)
